# Proyecto Final - Modelos Estadísticos Avanzados

![](https://www.theconstitutional.com/sites/default/files/Blog/ohio.JPEG)

Se utiliza un [dataset proveniente de kaggle](https://www.kaggle.com/datasets/uradkr/ohio-sold-real-estate-intelligence-2026). Contiene 21 columnas y +8 500 registros acerca de transacciones reales de ventas residenciales desde el año 1800 hasta el 2026 en Ohio, Estados Unidos. Incluye datos como el precio de venta, cantidad de baños y habitaciones, tamaño de la casa, año de venta, entre otros. El dataset representa un reto debido a su alta dimensionalidad, cantidad de valores nulos y valores atipicos.

Proyecto realizado por Claudio Poveda, Tiffany Méndez, Valeria Chinchilla, Stephanie Rodriguez y Mariel Rodriguez.
